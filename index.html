Dasar-Dasar Cloud

Tiga Model Cloud yang Wajib Kamu Pahami

POPULER
MODEL 01 · PUBLIC CLOUD

Public Cloud

Sumber daya komputasi disediakan oleh pihak ketiga (contoh: AWS, Azure, GCP) dan dapat diakses banyak pengguna sekaligus lewat internet. Biaya awal rendah, skalabilitas tinggi.

Pelajari Lebih Lanjut →
MODEL 02 · PRIVATE CLOUD

Private Cloud

Infrastruktur cloud yang dimiliki dan digunakan eksklusif oleh satu organisasi. Kontrol dan keamanan lebih tinggi, cocok untuk data sensitif seperti perbankan.

Pelajari Lebih Lanjut →
BARU
MODEL 03 · HYBRID CLOUD

Hybrid Cloud

Menggabungkan Public dan Private Cloud, sehingga beban kerja bisa dipindah sesuai kebutuhan keamanan, biaya, dan performa secara fleksibel.

FAQ Seputar Cloud Computing

Hybrid Cloud cocok saat organisasi butuh fleksibilitas Public Cloud untuk beban kerja umum, namun tetap ingin menyimpan data sensitif di Private Cloud.
