Kenalan Dengan Cloud

Public Cloud vs Private Cloud vs Hybrid Cloud

Apa itu Cloud Computing

Komputasi yang tidak terikat satu mesin

Cloud computing adalah cara mengakses sumber daya komputasi — seperti server, penyimpanan, dan jaringan — lewat internet, tanpa harus memiliki dan merawat perangkat keras sendiri secara langsung. Sejak awal 2010-an, konsep ini mengubah cara perusahaan membangun aplikasi.

Secara umum, cloud computing dibagi menjadi tiga model utama: Public Cloud, Private Cloud, dan Hybrid Cloud. Ketiganya punya kelebihan dan skenario penggunaan yang berbeda, tergantung kebutuhan keamanan, biaya, dan skala organisasi.

Catatan mentor: "Tidak ada satu model cloud yang 'paling benar' — semua tergantung kebutuhan bisnis."

Perbandingan

Ringkasan Tiga Model Cloud

Aspek Public Cloud Private Cloud Hybrid Cloud
Kepemilikan Pihak ketiga (AWS, Azure, GCP) Eksklusif satu organisasi Kombinasi keduanya
Biaya Awal Rendah, model bayar sesuai pakai Tinggi, butuh investasi infrastruktur Menengah, tergantung porsi campuran
Kontrol & Keamanan Terbatas, bergantung penyedia Penuh, dikelola sendiri Fleksibel sesuai jenis data
Skalabilitas Sangat tinggi Terbatas oleh kapasitas fisik Tinggi, bisa "meluap" ke public cloud
Contoh Penggunaan Startup, aplikasi dengan trafik fluktuatif Perbankan, instansi pemerintah Perusahaan besar dengan kebutuhan campuran
