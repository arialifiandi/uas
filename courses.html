KLS-101

AWS Cloud Practitioner

Kelas ini dirancang untuk pemula mutlak yang ingin memahami dasar Amazon Web Services (AWS), penyedia public cloud terbesar di dunia. Kamu akan belajar layanan inti seperti komputasi, penyimpanan, dan jaringan — seluruhnya lewat studi kasus nyata, bukan sekadar teori.

Silabus Singkat

  1. Pengenalan konsep dasar cloud computing dan model Public Cloud
  2. Layanan inti AWS: EC2 (komputasi), S3 (penyimpanan), VPC (jaringan)
  3. Konsep keamanan dan manajemen biaya di public cloud
  4. Proyek akhir: merancang arsitektur sederhana di AWS
